# KlockEditor 官网 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `官网/` 目录构建多页原生静态官网（落地页 + 体验页 + 文档站），扁平 × Fluent UI 风格，中英双语切换，内嵌真实编辑器。

**Architecture:** 零构建静态站。所有文案集中于 `assets/js/i18n.js` 字典（zh/en），页面用 `data-i18n` 键引用；`assets/css/site.css` 用 CSS 变量承载 Fluent 扁平设计令牌，`data-theme`（light/dark/auto）控制深浅色；`vendor/` 复制自项目根的 klock-editor 文件，体验页内嵌真实实例。每页静态复制共享 header/footer 标记（无模板引擎）。`tools/check-i18n.js`（Node 内置模块）扫描 HTML 中 `data-i18n` 键与字典覆盖，作为双语一致性的自检门禁。

**Tech Stack:** 原生 HTML / CSS / JS（ES5 兼容语法），Node.js ≥ 18（仅用于自检脚本与浏览器验证），Playwright MCP（最终页面验证）。

## Global Constraints

- 路径：所有路径相对页面自身（`assets/...`、`../assets/...`），双击 `官网/index.html` 离线可用。
- 品牌色：主强调色 `#e11d48`（玫瑰红，与 README 主题示例一致），辅助色 `#0f6cbd`（Fluent 蓝）；中性色板 Fluent：页面底 `#f3f2f1` / 卡片 `#ffffff` / 正文 `#323130` / 次要 `#605e5c` / 分割线 `#edebe9`；深色：底 `#1b1a19` / 卡 `#252423` / 正文 `#f3f2f1` / 次要 `#a19f9d` / 线 `#3b3a39`。
- 字体栈：`"Segoe UI", "Segoe UI Variable", system-ui, sans-serif`；代码：`"Cascadia Code", Consolas, monospace`。
- 圆角 4px，扁平（无重阴影），hover 浅色填充、active 按压反馈，`prefers-reduced-motion` 下禁用过渡。
- 语言偏好 `localStorage['klock-lang']`（`zh`/`en`），缺省 `navigator.language` 以 `zh` 开头则 `zh` 否则 `en`；主题偏好 `localStorage['klock-theme']`（`light`/`dark`/`auto`），缺省 `auto` 跟随 `prefers-color-scheme`。
- 不修改项目根目录现有文件（`vendor/` 只复制不追踪上游改动）；不改动 `docs/superpowers/specs/2026-08-16-website-design.md`。
- 每页 `<html lang>` 由 i18n 切换；所有交互元素有 `aria-label`；菜单按钮键盘可操作。
- 提交：每个 Task 独立 commit，Conventional Commits（`feat`/`docs`/`chore`），仅 `官网/`、`tools/` 与计划/规格文档入仓。

- [ ] **Step 1: 写 `tools/check-i18n.js`（Node 内置模块，无依赖）**

```js
const fs = require('fs');
const path = require('path');
const site = path.join(__dirname, '..', '官网');

const htmlFiles = [];
(function walk(dir) {
  for (const e of fs.readdirSync(dir, { withFileTypes: true })) {
    const p = path.join(dir, e.name);
    if (e.isDirectory()) walk(p);
    else if (e.name.endsWith('.html')) htmlFiles.push(p);
  }
})(site);

const src = fs.readFileSync(path.join(site, 'assets/js/i18n.js'), 'utf8');
const m = src.match(/window\.KlockI18n\.dict\s*=\s*(\{[\s\S]*?\n\});/);
if (!m) { console.error('dict block not found in i18n.js'); process.exit(1); }
let dict;
try {
  const json = m[1].replace(/([{,]\s*)(\w+)(\s*:)/g, '$1"$2$3').replace(/'/g, '"');
  dict = JSON.parse(json);
} catch (e) { console.error('dict parse failed:', e.message); process.exit(1); }

let fail = 0;
const used = new Set();
for (const f of htmlFiles) {
  const html = fs.readFileSync(f, 'utf8');
  for (const mm of html.matchAll(/data-i18n(?:-placeholder)?="([^"]+)"/g)) used.add(mm[1]);
}
for (const k of used) {
  if (!(k in dict)) { console.error('MISSING key in dict: ' + k); fail = 1; }
}
for (const k of Object.keys(dict)) {
  const d = dict[k];
  if (!d || !d.zh || !d.en) { console.error('INCOMPLETE lang for key: ' + k); fail = 1; }
}
process.exit(fail);
```

> 说明：dict 每项为 `{ zh: '...', en: '...' }`。`i18n.js` 是浏览器脚本，自检脚本用正则提取 `window.KlockI18n.dict = {...}` 的 JSON 体，把裸键补引号、单引号换双引号后 `JSON.parse`，不执行浏览器代码。

- [ ] **Step 2: 写 `assets/js/i18n.js` —— 基础字典 + 引擎**

```js
window.KlockI18n = (function () {
  var dict = {
    'nav.home':   { zh: '首页',   en: 'Home' },
    'nav.playground': { zh: '体验', en: 'Playground' },
    'nav.docs':   { zh: '文档',   en: 'Docs' },
    'foot.license': { zh: 'MIT 许可 · © 2026 KlockTX', en: 'MIT License · © 2026 KlockTX' },
    'foot.links': { zh: '项目仓库 · 文档 · 体验', en: 'Repository · Docs · Playground' }
  };
  var lang = 'zh';
  function detect() {
    var saved = null;
    try { saved = localStorage.getItem('klock-lang'); } catch (e) {}
    if (saved === 'zh' || saved === 'en') return saved;
    return (navigator.language || '').toLowerCase().indexOf('zh') === 0 ? 'zh' : 'en';
  }
  function apply() {
    document.documentElement.lang = lang;
    var toggle = document.getElementById('lang-toggle');
    if (toggle) toggle.textContent = lang === 'zh' ? 'EN' : '中';
    document.querySelectorAll('[data-i18n]').forEach(function (el) {
      var k = el.getAttribute('data-i18n');
      if (dict[k] && dict[k][lang]) el.textContent = dict[k][lang];
    });
    document.querySelectorAll('[data-i18n-placeholder]').forEach(function (el) {
      var k = el.getAttribute('data-i18n-placeholder');
      if (dict[k] && dict[k][lang]) el.setAttribute('placeholder', dict[k][lang]);
    });
    document.querySelectorAll('[data-lang]').forEach(function (el) {
      el.style.display = el.getAttribute('data-lang') === lang ? '' : 'none';
    });
  }
  function setLang(l) {
    lang = l;
    try { localStorage.setItem('klock-lang', l); } catch (e) {}
    apply();
  }
  function t(key) { return dict[key] ? dict[key][lang] : key; }
  document.addEventListener('DOMContentLoaded', function () {
    lang = detect();
    apply();
    var toggle = document.getElementById('lang-toggle');
    if (toggle) toggle.addEventListener('click', function () { setLang(lang === 'zh' ? 'en' : 'zh'); });
  });
  return { setLang: setLang, t: t };
})();
```

- [ ] **Step 3: 写 `assets/js/site.js` —— 主题/导航/复制**

```js
window.KlockSite = (function () {
  var THEMES = ['light', 'dark', 'auto'];
  function setTheme(mode) {
    var root = document.documentElement;
    var resolved = mode === 'auto'
      ? (window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light')
      : mode;
    root.setAttribute('data-theme', resolved);
    root.setAttribute('data-theme-mode', mode);
    try { localStorage.setItem('klock-theme', mode); } catch (e) {}
  }
  function copyCode(btn) {
    var code = btn.parentElement.querySelector('code').textContent;
    var done = function () {
      var old = btn.textContent;
      btn.textContent = '✓';
      setTimeout(function () { btn.textContent = old; }, 1500);
    };
    if (navigator.clipboard) navigator.clipboard.writeText(code).then(done);
    else {
      var ta = document.createElement('textarea');
      ta.value = code; document.body.appendChild(ta); ta.select();
      document.execCommand('copy'); document.body.removeChild(ta); done();
    }
  }
  document.addEventListener('DOMContentLoaded', function () {
    var saved = null;
    try { saved = localStorage.getItem('klock-theme'); } catch (e) {}
    setTheme(THEMES.indexOf(saved) > -1 ? saved : 'auto');
    var themeBtn = document.getElementById('theme-toggle');
    if (themeBtn) themeBtn.addEventListener('click', function () {
      var cur = document.documentElement.getAttribute('data-theme-mode') || 'auto';
      setTheme(THEMES[(THEMES.indexOf(cur) + 1) % 3]);
    });
    var navToggle = document.querySelector('.nav-toggle');
    var navLinks = document.querySelector('.nav-links');
    if (navToggle && navLinks) navToggle.addEventListener('click', function () {
      var open = navLinks.classList.toggle('is-open');
      navToggle.setAttribute('aria-expanded', open ? 'true' : 'false');
    });
    document.querySelectorAll('.copy-btn').forEach(function (b) {
      b.addEventListener('click', function () { copyCode(b); });
    });
    var href = location.pathname.split('/').pop() || 'index.html';
    document.querySelectorAll('.nav-links a').forEach(function (a) {
      if (a.getAttribute('href') === href) a.classList.add('is-active');
    });
  });
  return { setTheme: setTheme };
})();
```

    ['light', 'dark', 'auto'].forEach(function (m) {
      document.getElementById('theme-' + m).classList.toggle('is-active', m === mode);
    });
    if (root) root.setAttribute('data-theme', mode); // 组件支持 data-theme 强制主题
  }
  document.getElementById('mode-md').addEventListener('click', function () { setMode(true); });
  document.getElementById('mode-html').addEventListener('click', function () { setMode(false); });
  document.getElementById('theme-light').addEventListener('click', function () { setPlayTheme('light'); });
  document.getElementById('theme-dark').addEventListener('click', function () { setPlayTheme('dark'); });
  document.getElementById('theme-auto').addEventListener('click', function () { setPlayTheme('auto'); });
  refreshEcho();
